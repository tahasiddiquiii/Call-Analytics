# Introduction

## What this project is

Meridian Care (fictional) answers phone calls for many client brands: clinics, telecom, insurance, online shopping. A supervisor can listen to only a small fraction of calls. This system reads call transcripts and writes **one structured record per call**, so a supervisor can filter, count and compare calls, and other software can read the records without a person checking them first.

It uses a **small language model running locally on the CPU** (Qwen2.5-3B via Ollama): no hosted model service, no GPU, no internet once the model is downloaded.

```
data/calls/*.txt  ──►  python -m callanalytics data/calls  ──►  outputs/records.json
```

Each record holds the six required items (summary, intent, outcome, customer sentiment, action items, insights) plus fields for filtering and trust: call type, client brand, agent name, flags, supervisor priority, reference numbers, evidence quotes, `needs_review` with reasons, and processing data.

## Repository map

```
callanalytics/   the system: parser, model client, schema, references, grounding, privacy, rules, pipeline, CLI
prompts/         every prompt sent to the model
schema/          JSON Schema of the output file, for other software
outputs/         records.json, generated by the system (never edited by hand)
eval/            hand labels, evaluator, every run (v1–v4) with its prompts, model bake-off, held-out calls
tests/           30 unit and end-to-end tests (fake model, no Ollama needed)
scripts/         benchmark, bake-off, supervisor summary, slide and PDF builders
reports/         generated results: evaluation, benchmark, determinism, supervisor summary
docs/            all project documentation (this folder)
submission/      slides (PPTX + PDF) and the one-page write-up (MD + PDF)
data/calls/      the 10 provided transcripts
```

Generated reports (`reports/*.md`, `eval/runs/*/eval.md`), the prompts and the submission write-up stay next to the things that produce or use them. Everything written to *document* the project is in this folder.
